# Day 03 - Managing Resources

## Objective

Learn how to define and manage AWS resources using Terraform, understand resource dependencies, lifecycle management, and provisioners.

---

## Resources Created

- AWS EC2 Instance
- AWS Security Group
- AWS Key Pair
- AWS Default VPC

---

## Concepts Covered

- Terraform Resources
- AWS Provider
- Resource Arguments
- Implicit Resource Dependencies
- Default VPC
- Tags
- Root Block Device

---

## Terraform Workflow

```bash
terraform fmt
terraform init
terraform validate
terraform plan
terraform apply
terraform destroy
```

---

## Outcome

Successfully provisioned an EC2 instance along with its Security Group and Key Pair using Terraform. Explored how Terraform manages resource relationships.

---

## Learning Summary

- Learned how Terraform provisions AWS resources.
- Practiced infrastructure deployment and cleanup using Terraform.
